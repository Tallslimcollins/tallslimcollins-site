The Hazy Gray Diagnosis:
  • If RGB 0 looks foggy dark gray instead of pitch black: The LG monitor is suffering from either Black Stabilizer being boosted or an HDMI Black Level mismatch (High vs Low). Follow Fix #1 and Fix #2 on the right!
  • If the gradient ramp shows harsh bands or looks milky: Windows HDR is turned ON for an SDR monitor, or Picture Mode is in "FPS / RTS" gaming preset.

🔴 Fix The LG UltraGear (New Screen) GSM5C92 · 180Hz

  • Fix 1: Lower "Black Stabilizer" (The #1 Culprit!) 90% OF ISSUES
    Reach under the center bottom of the LG screen and press the joystick button inward to open the on-screen menu.
    Go to Game Adjust → Black Stabilizer.
    LG gaming presets default this to 60 or 70, which artificially brightens blacks into a hazy fog so gamers can spot targets. Lower Black Stabilizer to 40 – 50. Watch the foggy gray instantly snap into pure inky black!
  • Fix 2: Switch Picture Mode to "sRGB" or "Gamer 1"
    In the LG joystick menu, go to Picture Mode.
    Change it from FPS or Vivid to sRGB (or Standard).
    Why: The "sRGB" mode locks Gamma to industry-standard 2.2 and turns off aggressive game shadow boosting, making photos, artwork, and web colors 100% true to life.
  • Fix 3: Match HDMI "Black Level" (High vs Low)
    In the LG joystick menu, go to Picture → Picture Adjust → Black Level.
    • If Windows is sending Limited Range (16-235), setting Black Level to High causes gray haze! Switch it to Low.
    • If your black tones look crushed, switch back to High. Pick whichever setting makes RGB 0 jet-black without hiding box 16.
  • Fix 4: Turn OFF "Windows HDR" for the LG
    Open Windows Settings → System → Display → HDR.
    Ensure Use HDR is OFF on the LG monitor.
    Standard 1080p UltraGears do not have full-array local dimming; enabling Windows HDR forces an artificial washed-out gamma curve that turns Windows into a cloudy gray mess.

🔵 Samsung Screen (Reference) LF24T450F · 75Hz IPS

  • Target Baseline (The Reference)
    The Samsung F24T450F is a calibrated business IPS monitor with natural 1000:1 contrast and neutral color temperature.
    Use this screen as your color anchor. We want the LG screen to match this screen's black depth and white clarity.
  • Brightness & Contrast Balancing
    Set both monitors to roughly the same physical brightness in their on-screen menus (e.g. Brightness: 65-75, Contrast: 70).
    If the LG is glaringly brighter, reduce LG Brightness so white backgrounds look identical between both screens.
  • Windows Color Calibration Tool (DCCW)
    Press Windows Key + R, type dccw, and hit Enter.
    Drag the calibration wizard onto the LG screen. Step through the Gamma slider until the center dots fade into the circle.
⚡ Quick Summary: The Magic Trio
  1. LG Menu → Game Adjust → Black Stabilizer: Lower to 40-50.
  2. LG Menu → Picture Mode → Select sRGB.
  3. Windows Display Settings → HDR: OFF.
